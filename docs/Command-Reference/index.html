    Command reference¶

    This page lists every command F&O Studio contributes to VS Code (169 commands), grouped by area. For each command you get its title as VS Code shows it, its command ID (for your own keybindings and tasks), where you find it, and the wiki page that explains it.

    In the Command Palette (Ctrl+Shift+P) every command has the category F&O Studio, so you type for example F&O Studio: Build Project. Some commands are not in the Command Palette because they need a clicked element, node or row; they show "Context only" in the tables below.

    How to read the tables¶

    Term in the "Where" column Meaning
    Palette The Command Palette (Ctrl+Shift+P)
    Palette (UDE) The Command Palette, only when the active environment is a unified developer environment (hidden on cloud-hosted and VHD environments)
    Context only Not in the Command Palette; only in the menus listed
    AE menu Right-click menu of an element in the Application Explorer view
    Project menu Right-click menu of an element or node in the D365FO Project view
    Project title The toolbar or the ... menu at the top of the D365FO Project view
    Project > Project / Project > Check The Project and Check submenus in the ... menu of the D365FO Project view (shown when a project is open)
    AE title The toolbar or the ... menu at the top of the Application Explorer view
    Designer menu Right-click menu of a node in the element designer
    Designer title Buttons in the editor title bar of the element designer
    D365 view A node in the Dynamics 365 view (the group name follows, for example D365 view > Deploy)
    Status bar An item in the status bar

    The menus only show a command when it fits the element: for example Browse Table Data only on tables, Create Code Extension only on element types that support Chain of Command, Delete and Rename… only on elements of your own models.

    Keyboard shortcuts¶

    F&O Studio declares three keybindings. You can change them in File > Preferences > Keyboard Shortcuts.

    Key Command When
    Ctrl+Alt+O Open Element… (xpp.openObject) Always
    Ctrl+Shift+B Build Project (xpp.buildProject) In an X++ code view (xpp: document) or a .rnrproj file
    Ctrl+Shift+Alt+F Search Code in All Packages (xpp.searchCode) In an X++ editor, or when the Application Explorer, D365FO Project, Dynamics 365 or Infolog view has focus

    Other shortcuts you see in F&O Studio (F12, Shift+F12, Ctrl+F12, Ctrl+T, F2, Ctrl+.) are VS Code's own editor commands, which F&O Studio provides the X++ results for. See Go-to-Definition, Find-All-References, Implementations-and-Chain-of-Command, Outline-and-Workspace-Symbols, Rename-and-Refactoring and Quick-Fixes.

    Where the views are¶

    F&O Studio adds an F&O Studio container to the activity bar with four views, and an F&O Studio panel with three more:

    Container View View ID
    Activity bar Application Explorer xpp.aot
    Activity bar D365FO Project xpp.project
    Activity bar Security (collapsed at first) xpp.security
    Activity bar Dynamics 365 xpp.tools
    Panel Results xpp.results
    Panel Infolog xpp.infolog
    Panel Copilot Activity xpp.activity

    The Dynamics 365 view mirrors Visual Studio's Dynamics 365 menu. Its groups are Environment, Create, Build and check, Deploy, Data, Analyze, Find, Security, Labels, Model and project, Copilot, Debug and View and run, then Report a Problem…, the Code Intelligence group and Options…. On a cloud-hosted or VHD environment the UDE-only entries (Run Tests, Deploy Models to Online Environment…, Synchronize Database, Initialize Deployment Solution…, Clean Up Old Versions…, Sign In (pac)) are hidden.

    Binding your own keys¶

    Every command ID above can be bound to a key. Example for keybindings.json:

    [
  { "key": "ctrl+alt+r", "command": "xpp.reviewChanges" },
  { "key": "ctrl+alt+d", "command": "xpp.pac.deploy" }
]

    Commands marked "Context only" expect the clicked element or node as their argument, so they are not useful in a keybinding.
