    Scan Overlay and Measure¶

    The scan overlay lays a scanned or photographed form under the Report Designer's page, at the size of the paper it shows, so you can place each field on the preprinted stationery it will print on. The measure tool reads distances on the page in millimetres and inches. The scan is a design aid only: it is never saved in the report. Visual Studio's report designer has neither.

    When to use it¶

    • You design a report for preprinted stationery: cheques, purchase order or invoice forms, labels, government forms.
    • You have a sample of the form (a scan, a PDF converted to an image, or a photo) and need the fields where the boxes are.
    • You want to compare the rendered report with the scan in the Report-Preview.

    Before you start¶

    • A precision design open in the Report-Designer.
    • An image of the whole sheet: PNG, JPG/JPEG, BMP, GIF or TIF/TIFF. Scan at 100 % (no "fit to page") and keep the sheet straight; the overlay is not deskewed.
    • Set the design's paper size first (Properties with nothing selected → Paper (mm)), because a new scan is laid at the page size.

    How to use it¶

    Load a scan¶

    1. Click the camera button Scan overlay in the toolbar.
    2. Pick the image file.
    3. The scan appears under the page at the paper's width and height, at 45 % opacity, and the page properties show the Scan overlay (not saved in the report) group.

    Adjust it¶

    With nothing selected, the Properties panel shows, below the page settings:

    Setting Effect
    Paper Size the scan to Letter, Legal, A4, A5 or Executive, or Custom
    Width (mm), Height (mm) The size the whole image covers on the page
    Offset x (mm), Offset y (mm) Moves the scan from the sheet's top-left corner
    Opacity 0.1 to 1
    Remove scan Removes the scan from the designer

    To calibrate, measure a known distance on the scan with the measure tool (for example the width of a box printed as 50 mm) and change Width (mm) and Height (mm) until it reads right; then align a printed corner or rule with the offsets.

    Show or hide it¶

    Click the camera button again to hide the scan; once more to show it. The image stays loaded while the design is open in the panel (switching to another design clears it).

    Place fields on it¶

    1. Drag fields from Report data onto the boxes of the scan.
    2. Read the exact position in the status bar ("Name: x …, y …, width × height mm", from the sheet's top-left corner) or in Position (mm from the container).
    3. Nudge with Ctrl+arrow keys (0.1 mm) and resize with Shift+arrow keys.
    4. For fixed positions, keep Can grow off and padding at 0 (new textboxes are created that way); a growing textbox pushes the fields below it down (the designer warns about it).

    Compare in the preview¶

    1. Click Preview.
    2. Turn on Show scan under the page in the preview settings.
    3. Render. The rendered page is blended over the scan, so the report's text and the printed form show together.
    4. Type the values printed on the sample into Data (JSON rows per dataset) so the texts line up with the sample.

    Measure¶

    1. Click Measure (ruler button), or hold Alt and drag on the page at any time.
    2. Drag from one point to another. A line follows the pointer with the distance, for example "38.1 mm (Δx 38.1, Δy 0) · 1.5 in".
    3. When you release, the status bar keeps "Measured: …"; the line disappears after a few seconds.

    Escape cancels the measure tool. The status bar always shows the pointer position in mm and inches.

    What is remembered¶

    • The scan image stays in the panel's memory only. It is not saved in the report, the project or the workspace.
    • Its placement (size, offset, opacity and file name) is remembered per report design. When you reopen the design, the status bar says "A scan overlay was used last time (name); load it again with the camera button." Load the image again and it takes the remembered placement. Remove scan forgets the placement.

    Options and settings¶

    No settings. The placement is stored in the panel's state.

    How it works¶

    • The camera button asks the extension for a file (src/reports/reportDesigner.ts), which reads it and passes it to the webview as base64 data. The webview draws it as an image under the sheet (media/reportDesigner.js); nothing is sent to the server and nothing is uploaded.
    • Positions are computed from the RDL in millimetres (the page is drawn at 96 px per inch times the zoom), so readings don't depend on the zoom.
    • In the preview, the scan is placed with the same size and offset under each rendered page and the page image is blended with a multiply mode.

    With Copilot¶

    Copilot can do this end to end with the F&O Report Builder agent and its tools (see Agent-Tools-Reports and Copilot-Agents):

    • xpp_measure_image calibrates a scan (paper size, scan dpi or two reference points), straightens it, finds ruled lines and boxes, and reads the text with Windows' built-in OCR on this machine, with each position in mm.
    • xpp_compare_layout renders the design, lays it on the calibrated scan and returns an overlay plus each textbox's offset in mm.

    See Scenario-Report-from-a-Scanned-Document.

    Limitations¶

    • The overlay is not deskewed or scaled automatically; you size and offset it by hand. (xpp_measure_image does deskew and calibrate, for the agent.)
    • The image must be reloaded after the panel is closed.
    • PDF files can't be loaded directly; convert the page to an image first.
    • The measure tool shows a straight-line distance; it doesn't snap to items.

    Troubleshooting¶

    Symptom Cause Fix
    The scan doesn't match the page The image has margins or was scaled when scanned. Change Width (mm) and Height (mm) until a known distance measures right, then set the offsets.
    The scan settings aren't in the Properties panel An item is selected. Click an empty area of the page (or press Escape).
    The scan is gone after reopening Only the placement is remembered. Click the camera button and pick the same file.
    Fields are right in the designer but move in the preview Textboxes grow, or padding moves the text. Turn Can grow off and set padding to 0; check the warnings.
    Text in the preview looks wider than on the form A font isn't installed here and is substituted. See the font warning; check on the environment.
