# Projects and models

A **model** holds your elements (classes, tables, extensions); a **project** (`.rnrproj`, shared with Visual Studio) is the
working set you build, review and deploy. New elements go to the project's model.

In the **D365FO Project** view:

- **New Element** (`+`) creates a class, table, extension, menu item, privilege… or starts a wizard (batch job, report, workflow, service).
- **Build** (`Ctrl+Shift+B`) compiles the project.
- **Open Element** (`Ctrl+Alt+O`) finds any element by name; `t:cust` finds tables, `c:` classes, `f:` forms.
- The **…** menu has the project commands and the checks (best practice, Review My Changes, Pre-Deploy Checklist).
