# Build and fix

- **Ctrl+Shift+B** or the project in the status bar builds the project with the same compiler (xppc) and label compiler as Visual Studio. Unsaved code is saved first.
- Errors and warnings go to the **Problems** view, on the line of the method in the code view. **F8** / **Shift+F8** step through them.
- When a build fails, the notification offers **Show Problems** and **Show Output** (the full compiler log).
- **Build Models…** builds a whole model; best practice checks (xppbp) are in the project view's **Check** menu.
