# Look at the data

- **Browse Table Data** on a table (Application Explorer, project or designer) shows its rows with enum names, a company filter, column filters and sorting. Select a row to see all of its fields and follow relations to related tables.
- **New SQL Query** opens a read-only query panel with Explain Plan.
- **Cloud-hosted and VHD:** AxDB on this machine, Windows authentication.
- **Unified environments:** F&O Studio requests temporary database credentials for you (Reader or Writer); they are kept in VS Code's secret storage until they expire, shown in the status bar.

Copilot can read data too (`xpp_query_data`), always after your confirmation.
